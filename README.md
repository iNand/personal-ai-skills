# personal-ai-skills

A collection of open-source AI skills developed from personal life for productivity and life hacks.

**Completely free to use.** Feedback, improvements, and contributions of all kinds are very welcome!

## Purpose

These are practical AI skills (prompts, workflows, small tools, or agent instructions) that I have developed and refined in my own daily life. The goal is to share useful patterns for personal productivity and life hacks that others might find helpful.

## Structure

Skills will live in the `skills/` directory (coming soon). Each skill should be self-contained, clearly documented, and easy to adapt.

## Contributing

- Open an issue to suggest improvements or new ideas.
- Fork the repo and open a pull request.
- All constructive feedback is appreciated — from tiny fixes to entirely new skills.
